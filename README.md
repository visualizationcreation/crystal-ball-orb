# Crystal Ball ORB · Signals of Tomorrow

Fifteen dated predictions, eight themes and thirty supporting details in one sphere.
Explore sci-fi reveals, robots learning tasks, drone production, cooperating agents,
spaceflight, sport, culture, prices and weather. Ten World Watch companions and nine
unrecorded ORB Learn chapters complete the reader. Old audio has been retired.

Open index.html. Current content is embedded; sources need internet access.
See experiment-protocol.md and revision-notes.md for dates, changes and scoring.
The guesses do not establish AGI or foreknowledge. Keep misses and unresolved cases.
